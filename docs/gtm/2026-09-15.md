## Schedule Intent

The daily run is deliberately distribution-first:

- Discover fresh third-party discussions, directories, lists, issues, releases, and Amux mentions.
- Qualify opportunities by relevance, audience, freshness, and whether Amux materially helps.
- Create board cards and drafts for valuable responses, PRs, directory submissions, comparison updates, FAQ pages, demos, benchmark assets, and launch-channel posts.
- Avoid autonomous posting except on explicitly approved surfaces; otherwise leave a ready-to-review artifact with source URLs.
- Measure stars, forks, installs/proxies available locally, mentions, referrals, search/AEO signals, and conversions where the data is accessible.
- Append each run to `docs/gtm/YYYY-MM-DD.md` with queries, source URLs, artifacts, submitted items, drafts, skipped opportunities, metrics, and next actions.
